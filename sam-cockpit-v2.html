软件闲置率 i软件闲置率：买了但没发出去的席位占比，是"浪费"的直接度量。闲置率 = 未发放席位 ÷ 已采购席位
未发放席位 = 已采购席位 − 已发放席位席位只要已发放给具体使用人就算在用，不看登录频次。只统计"生效中"的资产——已过期、已停用的席位属于正常使用结束，不计入分子也不计入分母。数据来源：台账 user_seat_num（已采购）/ current_seat_num（已发放）

未发放即闲置 · 已过期/已停用不计入

台账状态分布 i台账状态分布：按合同/授权的生命周期状态，把全部软件资产分成三类，用来判断台账本身干不干净。生效中 = 已开通且在合同有效期内
待生效 = 已采购、尚未到启用日
已过期 = 已过合同到期日、未续约圆心百分比 = 生效中 ÷ 资产总数。已过期占比越高，说明台账清理越不及时。数据来源：台账 state + po_end_at
